# JooJae-Lab

> 주재 — 소리 내 읽으면 **주제**. 철자 틀린 거 아니에요 🙂

두 사람 이름에서 한 글자씩 따서 **주재**입니다.
정해둔 주제는 따로 없어요. 해보고 싶은 게 생기면 일단 만들어 봅니다.
굳이 주제를 꼽자면, 저희가 주제예요.

## 같이 작업할 때

- [브랜치 전략 & 협업 가이드](https://github.com/JooJae-Lab/.github/blob/main/docs/branch-strategy.md)
- [Claude Code 플러그인](https://github.com/JooJae-Lab/claude-plugins)

```
main ◀── release/vX.Y.Z ◀── feature/vX.Y.Z ◀── feat/*, fix/* ...
main ◀── hotfix/vX.Y.Z
```

커밋·PR 제목은 `타입: 한국어 설명` · `main` 으로 가는 PR 은 리뷰 1명 · CI 통과 필수
